# Origin Technologies

Origin Technologies is developing software for quantitative research, strategy evaluation, and agent-assisted project coordination.

## Projects

- **OriginHQ** is a workspace for coordinating software projects and coding agents.
- **OriginFX** provides FX research and strategy-evaluation tools.
- **OriginCT** provides crypto research and paper-trading tools.

These projects are in active development. Implementation repositories are maintained privately.

Founded by [Kyle](https://github.com/OriginTech-Y2Kyle).
